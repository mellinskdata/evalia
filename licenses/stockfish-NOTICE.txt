Stockfish integration notice
============================

Evalia does not bundle a Stockfish executable in this source ZIP.
On Windows, when the user starts an engine analysis and no local engine is configured,
Evalia downloads the current stable Windows x64 release from the official Stockfish
GitHub repository and stores it locally under engine/stockfish.exe.
