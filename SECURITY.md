# Security and privacy

Evalia accesses public chess account data without requesting account passwords. Game archives and local settings are stored under the `data/` directory, which is excluded from version control.

Do not commit real player-account exports, private PGN archives, access tokens, engine binaries, or local configuration files. Review data and generated reports before sharing them.

If you discover a security issue, contact the repository maintainer privately rather than posting secrets in a public issue.
